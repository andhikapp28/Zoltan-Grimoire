How this connects
This page tries to reach the game directly over Chrome's remote-debugging port. When that works, every button below runs immediately — no console needed. When the browser blocks it (some do, as a security measure), buttons fall back to copying the script instead.
  1. Launch the game, then open Chrome and go to http://127.0.0.1:9222 once — this confirms the port is reachable and warms up the target list
  2. Come back here — the dot above turns green once connected
  3. If it stays red: click the index target at that URL yourself (not the "generated background page"), keep that tab open, then paste what gets copied here into its Console tab
