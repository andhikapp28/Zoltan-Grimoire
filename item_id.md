## Console cheat commands

All of these run in the DevTools console (see the remote-debugging setup notes earlier in
this project). They act on the *live* game state — effects show up immediately and get
saved next time you save in-game.

> ⚠️ Chrome DevTools console quirk: top-level `const`/`let`/`function` declarations persist
> across separate pastes in the same session, so re-running a script that declares
> `const CATEGORY = ...` a second time throws `Uncaught SyntaxError: Identifier '...' has
> already been declared`. Any multi-line script below with top-level `const`/`function` should
> be wrapped in `(function () { ... })();` if you plan to re-run it more than once per session.

### Items / inventory

```js
// inspect current contents of a specific list
console.table($gameSystem.inventory.map((s,i)=>({slot:i, itemId:s[0], qty:s[1]})));

// scan every storage for all unique item IDs currently held
(() => {
  const seen = new Set();
  const scan = (list) => { if (list) list.forEach(s => { if (s[0] !== 0) seen.add(s[0]); }); };
  scan($gameSystem.inventory);
  scan($gameSystem.Handitem);
  for (let i = 1; i <= 39; i++) scan($gameSystem['chest' + i]);
  console.log(JSON.stringify([...seen].sort((a,b)=>a-b)));
})();

// change qty of an item that's already there
function setItemQty(list, itemId, qty) {
    const slot = list.find(s => s[0] === itemId);
    if (slot) { slot[1] = qty; }
}

// add a new item into an empty slot
function addItem(list, itemId, qty) {
    const empty = list.find(s => s[0] === 0);
    if (empty) { empty[0] = itemId; empty[1] = qty; }
}
// example: addItem($gameSystem.inventory, 261, 99);  // 99x Potion
```

### Weapons / Armors — ⚠️ cheat commands don't reliably work here

Materials/food/herbs live in the custom `$gameSystem.inventory`/`Handitem` arrays above, keyed
by `Items.json` IDs, and cheating those in works fine (confirmed).

**Weapons/armors are different and confirmed NOT to work as a usable cheat**, even though the
data technically writes successfully:

```js
$gameParty.gainItem($dataWeapons[81], 1);  // "works" — $gameParty._weapons does get {"81":1}...
$gameActors.actor(1).changeEquip(0, $dataWeapons[81]); // ...but this also didn't make it show up
```

Confirmed by testing (2026-08-15): `gainItem` genuinely writes into `$gameParty._weapons`/
`_armors` (verified via `console.log(JSON.stringify($gameParty._weapons))`), but this game's
custom crafting/inventory UI never reads from that vanilla container, so the item never
becomes visible or usable anywhere in-game. `changeEquip` didn't help either. Equip slot
order for reference, from `System.json` (`equipTypes`): `0=Weapon, 1=Body, 2=Leg, 3=Accessory,
5=Title` — a custom layout, not RPG Maker's default.

**Conclusion: for weapons/armor, just craft them normally in-game** (Smithing menu — see the
`smith_weapon`/`smith_armor`/`smith_leg`/`smith_accessory` categories in `system` data). The
underlying storage mechanism the crafting UI actually reads from hasn't been identified yet —
if that gets found later, update this section.

### Instant strike while fishing

From reading `SlowLife_fishing.js`: while you're waiting for a bite, `$gameSystem.fishing.count`
ticks up every frame until it reaches `$gameSystem.fishing.waittime` (a random delay based on
your rod's tier) — that's the moment the game plays the "bite" sound/reaction and gives you a
~90-frame window to strike. Force that moment to happen right now:

```js
// one-shot: run this any time after casting, while you're still waiting
$gameSystem.fishing.count = $gameSystem.fishing.waittime;
```

Or, for a "set and forget" version that auto-forces an instant bite on every cast without
needing to re-run it — polls in the background and only acts while a wait is actually in
progress:

```js
window._instantFishInterval = setInterval(() => {
    const f = $gameSystem.fishing;
    if (f && f.waittime > 0 && f.count < f.waittime) f.count = f.waittime;
}, 100);

// to turn it off later:
clearInterval(window._instantFishInterval);
```

### Instant-win the fishing tournament (釣り大会)

From the same plugin's `SL_FishTnmt_*` functions: your tournament score is
`$gameSystem.fishing.TnmtRed.Point`, the 11 rivals have separate pre-scripted scores in
`RivalPoint[]`, and when the countdown timer `$gameSystem.fishing.TnmtTime` hits 0, everyone
(you + 11 rivals) gets sorted descending by score — your position in that sort *is* your rank
(1st place = highest score, no other logic involved).

```js
$gameSystem.fishing.TnmtRed.Point = 9999; // guaranteed higher than any rival
$gameSystem.fishing.TnmtTime = 0;         // end the tournament immediately -> results screen
```

Run this any time after the tournament has started (talk to the NPC to begin it first) —
you'll get an instant 1st-place result without needing to actually fish.

### God Mode (party can't be damaged)

Patches `Game_Actor` only, so enemies still take damage normally — only your own party
becomes unkillable. Needs to be re-run after every game restart (it's a live patch, not
saved to the file).

```js
Game_Actor.prototype.gainHp = function(value) {
    if (value < 0) value = 0; // ignore incoming damage
    this._result.hpDamage = -value;
    this._result.hpAffected = true;
    this.setHp(this.hp + value);
};
```

To undo mid-session (e.g. you want damage back on): reload the page (`location.reload()`)
or restart the game.

### Win the sauna battle royale instantly

From `SlowLife_sauna.js`: `$gameSystem.saunaChara` holds all 4 participants — `[1]` is always
you ("red"), `[2]`–`[4]` are the 3 random opponents. The game's own damage function accepts
`"enemy"` as a target to hit everyone except you at once, and its own death-check already
declares victory once all opponents are dead — so this reuses real game logic instead of
faking a result:

```js
$gameMap.SL_SaunaHPgain(-9999, "enemy"); // instantly kills all 3 opponents -> auto win
```

Optional, top off your own HP first if the fight's already underway:
```js
$gameSystem.saunaChara[1].hp = $gameSystem.saunaChara[1].maxhp;
```

### Instant harvest all crops

From `SlowLife_farm.js`: each farm plot stores a dynamic key pair on `$gameSystem` —
`planttime<mapId><eventId>` (when it was planted, in `$gameSystem.timecount` units) and
`plantcultivation<mapId><eventId>` (how long it needs to grow). The ready-to-harvest check is
simply `timecount - planttime >= plantcultivation`. Zeroing every `planttime*` key makes that
gap huge for every plot on every map at once, no need to know map/event IDs:

```js
Object.keys($gameSystem).forEach(key => {
    if (key.startsWith('planttime')) {
        $gameSystem[key] = 0;
    }
});
```

Run it, then go harvest as normal — everything currently planted (any plot, any map) is
instantly ready.

### Sort/tidy the 4 chests by category

Pools everything currently sitting in `chest1`–`chest4`, merges duplicate stacks of the same
item, and redistributes into a fixed layout: **chest1 = plants** (herbs/crops/fruit/flowers/
mushrooms/seeds), **chest2 = materials/minerals + potions** (wood/stone/ore/ingots, medicine),
**chest3 = monster drops + fish/sea catch**, **chest4 = everything else** (cooked food, shop
ingredients, currency, misc, crafted gear). Confirmed working (2026-08-15).

> Discovery (2026-08-15): crafted **armor/accessories** use offset **ID = 10000 + Armors.json
> index** (e.g. `10003` = Adventurer's Clothes, `10140` = Leather Gloves) — a *different*
> offset from crafted weapons (`+1000`, see the crafted-items table above). Both ranges are
> just routed straight to chest4 by the `id >= 1000` check below rather than listed individually.

```js
// crafted weapon (+1000) / armor (+10000) always -> chest4, no need to whitelist every ID
function categorize(id) {
  if (id >= 1000) return 4;
  return CATEGORY[id] || 4;
}

function sortChestsByCategory(keys) {
  const buckets = {1:[], 2:[], 3:[], 4:[]};
  const uncategorized = [];

  for (const key of keys) {
    const list = $gameSystem[key];
    if (!list) continue;
    for (const slot of list) {
      const [id, qty, extra] = slot;
      if (id === 0) continue;
      const cat = categorize(id);
      if (id < 1000 && !CATEGORY[id]) uncategorized.push(id);
      const hasExtra = extra && extra.some(v => v !== 0);
      buckets[cat].push({ id, qty, extra, hasExtra });
    }
  }

  for (const cat of [1,2,3,4]) {
    const merged = {};
    const keep = [];
    for (const item of buckets[cat]) {
      if (item.hasExtra) {
        keep.push([item.id, item.qty, item.extra]);
      } else {
        merged[item.id] = (merged[item.id] || 0) + item.qty;
      }
    }
    const mergedSlots = Object.keys(merged)
      .map(id => [Number(id), merged[id], [0,0,0,0,0,0]])
      .sort((a,b) => a[0]-b[0]);
    buckets[cat] = [...mergedSlots, ...keep];
  }

  const chestKeys = ['chest1','chest2','chest3','chest4'];
  for (let c = 0; c < 4; c++) {
    const list = $gameSystem[chestKeys[c]];
    const data = buckets[c+1];
    for (let i = 0; i < list.length; i++) {
      if (i < data.length) {
        list[i][0] = data[i][0];
        list[i][1] = data[i][1];
        list[i][2] = data[i][2];
      } else {
        list[i][0] = 0;
        list[i][1] = 0;
        list[i][2] = [0,0,0,0,0,0];
      }
    }
    if (data.length > list.length) {
      console.warn(`chest${c+1} kelebihan ${data.length - list.length} jenis item, slot nggak cukup!`);
    }
  }

  if (uncategorized.length) {
    console.warn('Item ID belum ada kategori (masuk default chest4):', [...new Set(uncategorized)]);
  }
}

sortChestsByCategory(['chest1','chest2','chest3','chest4']);
```

If new item IDs show up that aren't in `CATEGORY` yet, they silently default to chest4 and get
logged as a console warning — add them to the right bucket above and re-run as needed.

### Generic tidy (merge duplicates + compact empties, no cross-storage moving)

Simpler version — cleans up one storage array in place without moving anything between chests.
Useful for `inventory`/`Handitem`, or a single chest.

```js
function tidyStorage(list) {
    const merged = {};
    const keep = [];

    for (const slot of list) {
        const [id, qty, extra] = slot;
        if (id === 0) continue;
        const hasExtra = extra && extra.some(v => v !== 0);
        if (hasExtra) {
            keep.push([id, qty, extra]);
        } else {
            merged[id] = (merged[id] || 0) + qty;
        }
    }

    const mergedSlots = Object.keys(merged)
        .map(id => [Number(id), merged[id], [0,0,0,0,0,0]])
        .sort((a, b) => a[0] - b[0]);

    const combined = [...mergedSlots, ...keep];

    for (let i = 0; i < list.length; i++) {
        if (i < combined.length) {
            list[i][0] = combined[i][0];
            list[i][1] = combined[i][1];
            list[i][2] = combined[i][2];
        } else {
            list[i][0] = 0;
            list[i][1] = 0;
            list[i][2] = [0, 0, 0, 0, 0, 0];
        }
    }
}

['inventory', 'Handitem', 'chest1', 'chest2', 'chest3', 'chest4'].forEach(key => {
    if ($gameSystem[key]) tidyStorage($gameSystem[key]);
});
```
